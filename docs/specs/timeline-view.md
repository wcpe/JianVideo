# 功能规格：时间轴视图

> 状态：开发中　·　关联 PRD：FR-14　·　分支：feature/fr-14-timeline

## 1. 背景与目标

用户需要将媒体库中的视频按添加时间倒序浏览，类似社交媒体的"信息流"模式，方便快速发现最新入库的视频。属于第一期 MVP 的核心浏览界面。

## 2. 需求（要什么）

- 前端提供时间轴视图页面，媒体文件按 `added_at` 倒序排列（默认），支持切换为 `time_asc`（正序）和 `name`（文件名排序）
- 媒体卡片展示：文件名、时长（格式化为 HH:MM:SS 或 MM:SS）、分辨率（如 1920×1080）、文件大小（人类可读格式）
- 支持分页浏览，默认每页 20 条，最大 100 条
- 调用后端 `GET /api/library/media?sort=time_desc&page=1&page_size=20` 获取数据
- 路由为 `/timeline`，通过侧边栏导航进入

范围内：
- 时间轴视图页面（信息流布局）
- 媒体卡片组件
- 排序切换（time_desc / time_asc / name）
- 分页控制
- 后端 API 已就绪（FR-01 实现），直接消费

不做（范围外）：
- 缩略图生成（需要后端 FFmpeg 截图接口，后续版本支持）
- 搜索功能（FR-15 文件目录视图中实现）
- 播放功能（点击卡片跳转播放页面，后续 FR 实现）

## 3. 设计（怎么做）

### 后端

后端已在 FR-01 中实现完整的媒体文件列表 API，支持 `sort`、`page`、`page_size` 参数。FR-14 无需修改后端代码。

接口契约见 `docs/API.md` §"获取媒体文件列表"。

### 前端

- 使用 React 19 + TypeScript 6 + Vite 8 构建
- UI 框架：shadcn/ui + Tailwind CSS 4
- 状态管理：zustand（轻量级，适合当前规模）
- HTTP 客户端：axios
- 路由：react-router-dom v7

#### 核心组件

| 组件 | 职责 |
|---|---|
| `TimelinePage` | 页面容器，管理数据加载、分页、排序状态 |
| `MediaCard` | 单张媒体卡片，展示文件元信息 |
| `SortSelector` | 排序方式切换器 |
| `Pagination` | 分页控件 |
