# 功能规格：时间轴视图

> 状态：开发中　·　关联 PRD：FR-14　·　分支：feature/fr-14-timeline

## 1. 背景与目标

用户需要将媒体库中的图片和视频按添加时间倒序浏览，类似社交媒体的"信息流"模式，方便快速发现最新入库的媒体资源。属于第一期 MVP 的核心浏览界面。

## 2. 需求（要什么）

- 前端提供独立 `/timeline` 时间轴路由，媒体文件按 `added_at` 倒序排列（默认显式传 `sort=time_desc`），支持切换为 `time_asc`（正序）和 `name`（文件名排序）
- 媒体卡片展示：文件名、视频时长（格式化为 HH:MM:SS 或 MM:SS）、分辨率（如 1920×1080）、文件大小（人类可读格式）；图片不展示时长并支持预览
- 支持分页浏览，默认每页 20 条，最大 100 条
- 调用后端 `GET /api/library/media?sort=time_desc&page=1&page_size=20` 获取数据
- 路由为 `/timeline`，通过侧边栏导航进入

范围内：
- 时间轴视图页面（信息流布局）
- 媒体卡片组件
- 排序切换（time_desc / time_asc / name）
- 分页控制
- 后端 API 已就绪（FR-01 实现），直接消费

不做（范围外）：
- 视频缩略图生成（需要后端 FFmpeg 截图接口，后续版本支持；图片使用 raw 预览接口）
- 搜索功能（FR-15 文件目录视图中实现）
- 图片编辑/下载功能；视频点击卡片仍跳转播放页面

## 3. 设计（怎么做）

### 后端

后端媒体文件列表 API 支持 `sort`、`page`、`page_size` 参数；图片预览通过 `GET /api/library/media/:id/raw` 获取本地图片原始内容。

接口契约见 `docs/API.md` §"获取媒体文件列表"。

### 前端

- 使用 React 19 + TypeScript 6 + Vite 8 构建
- UI 框架：Mantine UI v9
- 状态管理：zustand（轻量级，适合当前规模）
- HTTP 客户端：axios
- 路由：react-router-dom v7

#### 核心组件

| 组件 | 职责 |
|---|---|
| `LibraryPage(initialTab="timeline")` | 时间轴页面容器，管理数据加载、分页、搜索和默认排序状态 |
| 媒体卡片 | 单张媒体卡片，展示文件元信息，图片点击打开预览，视频点击跳转播放页 |
| `Pagination` | 分页控件 |
