# 功能规格：目录浏览重做为资源管理器 + 真实路径树（Directory Real-path Explorer）

> 状态：开发中　·　关联 PRD：FR-121（取代 ADR-0037，扩 FR-33/FR-66）　·　分支：feature/directory-realpath-explorer

## 1. 背景与目标

现有目录浏览（`/browse`，FR-66/ADR-0037）把**每个媒体库当独立虚拟根并列**、靠 `library_id` 逐库下钻——看不出库间真实路径包含关系（加 `D:\1` 与 `D:\1\2` 显示成两个并排库）。本特性按用户诉求重做：① 聚合改为**按真实磁盘路径跨库重建单一目录树**（盘符/共享为根，传 `D:\` 库即整盘可浏览）；② 前端重做成 **Windows 资源管理器**式（左导航树 + 可点地址栏 + 工具栏 + 名称/修改日期/类型/大小详情列 + 状态栏 + 视图模式）；③ 移除全局页级面包屑 `PageBreadcrumbs`。**只读浏览，不做真动磁盘文件操作**。取代 ADR-0037（见 ADR-0046）。属第十二期、本批最后一条。

## 2. 需求（要什么）

- **真实路径树聚合**（后端）：浏览任意真实路径 P 时，子目录 = P 下一级所有有索引文件的目录（**跨所有库合并、不分库**）、文件 = P 直属文件；顶层 = 各盘符/共享根；传 `D:\` 库即整盘可浏览。
- **排序后端参数化**：`name` / `size` / `type` / `time`（修改时间）。
- **资源管理器 UI**（前端）：左导航树（懒展开）+ 可点地址栏（路径段）+ 工具栏（下载/加相册/打标签/删除 + 视图/排序）+ 详情列（名称/修改日期/类型/大小）+ 状态栏（项目数/选中）+ 视图模式（详情/列表/大中小图标）。
- **移除全局面包屑**：删除 `PageBreadcrumbs` 在目录/相册/播放三页的使用（用资源管理器地址栏取代目录页的路径导航）。

- 范围内：上述聚合重做 + 排序参数 + Explorer UI + 移除 PageBreadcrumbs。复用既有 FR-69 多选/FR-34 详情/FR-91 批量/FR-36 筛选搜索/FR-33 视图模式。
- 不做（范围外，禁镀金）：复制/剪切/粘贴/移动/新建文件夹等**真动磁盘**操作；改库注册方式；改 media_files 真源。

## 3. 设计（怎么做）

### 3.1 后端：真实路径树聚合（取代 ADR-0037）

重做 `internal/library` 的 `BrowseDirectory`（现 service.go:472-563 的虚拟库根 + 单库前缀逻辑）：

- **顶层根**（`parent_path == "__root__"`）：列出**各盘符/共享根**——取所有启用 `library_paths` 的 `path`，各推导其卷根（本地 `D:/...` → `D:`；UNC `//host/share/...` → `//host/share`），去重排序作为顶层目录项。面包屑单段 `{name:"全部", path:"__root__"}`，无文件。
- **浏览真实路径 P**（`parent_path != "__root__"`，**不再依赖 library_id**）：
  - 子目录 = `SELECT DISTINCT 下一级段` FROM media_files WHERE `file_path LIKE 'P/%'`（大小写不敏感，复用既有 `trimPathPrefix`）AND `deleted_at IS NULL`（**跨所有库**，不加 library_id 过滤）。
  - 文件 = media_files 中目录恰为 P 的项（相对路径不含 `/`）、未软删，**跨所有库**。
  - 面包屑 = P 按分隔符拆段累进（保持 `D:/...` 形式，不加 `/D:`）。
  - **排序**：按 `sort`（name/size/type/time）服务端排文件（目录恒在前、按名）。
- `DirInfo.library_id` 对子目录不再填（子目录可跨库）；文件仍各带自身 `library_id`（供删除/下载等操作）。
- 性能：`file_path` 已有索引，前缀查询满足 NFR-08；大目录（整盘）子目录聚合走「一次前缀查询 + Go 层去重分组」，文件列表受当前目录（非递归）约束、量可控。
- **端点** `GET /api/library/browse?parent_path=&sort=`：保留 `parent_path`（向后兼容），`library_id` 参数变为可选/忽略（导航按路径），新增可选 `sort`。响应结构（breadcrumbs/directories/files）不变。

### 3.2 后端：契约与迁移

- 行为变更：同一 `parent_path` 现返回**跨库合并**结果（旧为单库）。更新既有 browse 测试到新语义（虚拟根列盘符根、跨库前缀合并、sort 生效）——属预期内变更，非回归。
- ADR-0046 取代 ADR-0037（旧 ADR 状态改「已被 ADR-0046 取代」，正文不改）。

### 3.3 前端：资源管理器 UI

把 `/browse`（BrowsePage + DirectoryBrowser）重做为 Explorer 布局（复用既有数据 hook `useDirectoryBrowse`、视图模式 `DisplayMode`、`sortFiles`、`useMultiSelect`、右键批量、`MediaDetailPanel`）：

- **顶部工具栏**：上一级/刷新 + 下载/加相册/打标签/删除（复用 FR-91/FR-69 批量动作）+ 右侧 视图模式（详情/列表/大中小）+ 排序（接后端 `sort`）。
- **地址栏**：可点路径段（消费后端 `breadcrumbs`，点击跳该层）+ 当前目录搜索框（复用 FR-36 在当前目录递归筛选）。
- **左导航树**：聚合根 → 盘符/共享 → 子目录，懒展开（点节点调 browse 取子目录）；当前路径高亮。
- **主区**：
  - 详情视图：名称/修改日期/类型/大小列表（数据来自 media_files 的 file_name/modified_at/format/file_size；目录行大小显「—」、类型「文件夹」）。
  - 图标视图（大/中/小）：复用现有缩略图网格。
  - 双击目录进入、双击文件打开详情面板/播放（复用 FR-34）。
- **状态栏**：`N 个项目` + 选中数与大小。
- 移动端：左树可收进抽屉、地址栏可横滚（沿用 FR-86 响应式惯例）。

### 3.4 前端：移除全局面包屑

- 删除 `PageBreadcrumbs` 在 `BrowsePage`、`AlbumsPage`、`PlayPage` 的使用；目录页路径导航改由资源管理器地址栏承担。
- `PageBreadcrumbs` 组件及其测试若再无引用则一并删除（精准清理因本改动而孤立的代码）。

### 3.5 架构

见 ADR-0046（目录浏览聚合由虚拟库根改为真实路径树，取代 ADR-0037）。同步 ARCHITECTURE §5.0 与 API.md。

## 5. 验收标准

- **AC-25**（见 PRD §6）：`/browse` 为资源管理器布局（左树 + 地址栏 + 工具栏 + 名称/修改日期/类型/大小详情列 + 状态栏 + 视图模式）；目录树按**真实磁盘路径跨库合并**（加 `D:\1` 与 `D:\1\2` 在 `D:` 下合成 `1 → 2` 单一树；加 `D:\` 库则整盘可浏览）；排序经后端 `sort` 生效；地址栏路径段可点跳转；多选/详情/批量/筛选既有交互不回归；全局页级面包屑已移除。
- 后端 browse 单测覆盖：盘符根列举、跨库真实路径合并、整盘根、sort（name/size/type/time）、软删排除、Windows 大小写不敏感前缀；既有 browse 测试更新到新语义且通过。
- 受影响前端跑生产构建（`npm run build`）+ vitest 全绿（含重做的 browse 相关测试与移除 PageBreadcrumbs 后的回归）。
- 资源管理器观感 / 左树懒展开 / 真实路径树正确性 **真机走查**待真机。

## 6. 风险 / 待定

- 跨库前缀聚合在整盘（`D:\`）大库下可能命中大量文件：子目录聚合走「DISTINCT 下一级 + Go 去重」，文件列表受当前目录（非递归）约束、量可控；必要时复用既有上限。
- 卷根推导需兼容本地盘符与 UNC/SMB 共享根；SMB 路径按既有规范化（正斜杠）处理。
- 行为变更（单库→跨库合并）会改既有 browse 测试预期——属预期内，随实现更新，不是回归。
- 移除 PageBreadcrumbs 影响相册/播放页顶部：确认这两页移除后无布局塌陷（标题/返回仍可用）。
