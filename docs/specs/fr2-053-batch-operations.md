# 功能规格：批量操作

> 状态：已交付@v0.25.0　·　关联 PRD：FR2-053　·　阶段：P4 `0.25.x`　·　前置：FR-69 多选、FR-91 批量加相册/标签/zip、`batch-delete`

## 1. 背景与目标

已有多选、批量删除、加相册、打标签、打包下载。PRD FR2-053 要求 **批量转码 / 打标签 / 移动 / 删除**。本规格在既有基建上补齐转码与移动，并收口标签/删除体验。

## 2. 范围

### 2.1 范围内

- **批量打标签**：保持 FR-91 循环单项 API；失败计数 toast。
- **批量删除**：保持软删/回收站语义与确认框。
- **批量转码**：对选中视频入队既有 HLS/ABR 转码任务；跳过非视频；上限 N（默认 100）。
- **批量移动**：在库内变更逻辑路径/所属 library（不物理搬原文件除非已有安全移动能力）；若当前仅支持改 `library_id`/路径索引，则只做索引层移动并写审计；物理搬迁若未就绪则明确 disabled + 说明。
- 右键菜单与工具栏入口一致；Browse/Timeline 共用 `useBatchActions`。

### 2.2 范围外

- 批量改元数据写回、批量分享、批量 AI。
- 匿名用户批量高成本转码。

## 3. 设计

- `POST /api/library/media/batch-transcode`：`ids[]` + preset/profile；内部循环 Enqueue，幂等。
- `POST /api/library/media/batch-move`：`ids[]` + `target_library_id` 或 `target_path`；事务批处理 + 审计。
- 前端：扩展 `useBatchActions`；进度以任务中心为准，不阻塞 UI。

## 5. 验收标准

- 选中混合图片/视频时，转码只处理视频并提示跳过数。
- 批量打标签/删除行为与现网一致且有测试。
- 批量移动后列表在目标库可见、源库不可见（索引语义）。
- 超限返回 400；部分失败不中断已入队项的统计展示。

## 6. 风险

- 物理文件移动与 SMB 权限：首期索引层移动，物理搬迁另开规格。
