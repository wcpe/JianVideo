# 功能规格：元数据与标签前端展示

> 状态：候选发布@v0.25.0-rc.1　·　关联 PRD：FR2-032　·　阶段：P4 `0.25.x`　·　前置：[fr2-030](fr2-030-embedded-metadata.md)、[fr2-031](fr2-031-offline-title-inference.md)

## 1. 背景与目标

FR2-030/031 已提供嵌入元数据 API、推断记录与 `MediaDetailPanel` 部分展示。P4 要求详情面板完整展示技术元数据、标签与推断信息，并支持按元数据/标签筛选（筛选能力与 FR2-046 协同）。

## 2. 范围

### 2.1 范围内

- 详情面板分区展示：基础文件信息、视频/图片技术元数据、标签列表、离线推断（片名/季/集）、来源与解析时间。
- 标签：展示媒体标签、支持从详情跳到「按该标签筛选」。
- 与列表筛选联动：`tag_id`、推断状态、时长/分辨率等（后端字段见 FR2-046）。
- 元数据加载失败时中文错误提示，不阻塞预览/播放。

### 2.2 范围外

- 写回原文件与危险编辑（FR2-033，P5）。
- 联网刮削。
- 在详情内完成图片调色/视频剪辑（FR2-038/039）。

## 3. 设计

- 复用 `GET /api/library/media/:id/metadata`、`ListMediaTags`、推断接口。
- `MediaDetailPanel` 增加清晰分区与空态；长字段可复制。
- 筛选入口：标签 chip 点击 → 父页设置 `tag_id` 并关闭或保留面板（保持现有 Browse/Timeline 状态模型）。
- 不新增「全量前端缓存元数据」；按当前选中媒体按需请求。

## 4. 任务拆分

- [x] 规格冻结（本文）。
- [x] 详情面板分区与标签/推断完整展示 + vitest。
- [x] 标签 chip → 列表筛选联动（Timeline 设 tag_id；Browse 用标签名搜索兜底）。
- [x] 文档与 CHANGELOG。

## 5. 验收标准

- 有嵌入元数据的视频/图片在详情中可见编码、分辨率、时长、音轨/字幕摘要或 EXIF 关键字段。
- 有标签时列表展示正确；点击标签可筛出该标签媒体。
- 有推断信息时展示片名与季/集；无推断时明确空态。
- 元数据接口 404/失败时面板不崩溃，提示中文错误。

## 6. 风险

- 大 JSON 元数据渲染性能：默认折叠原始 JSON，只展开规范化字段。
