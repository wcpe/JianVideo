# 功能规格：图片灯箱交互增强（FR-105）

> 状态：开发中　·　关联 PRD：FR-105（扩 FR-34）　·　分支：feature/fr-105-image-lightbox

## 1. 背景与目标

`MediaDetailPanel`（文件详情面板，FR-34）的图片预览此前仅支持滚轮缩放（1–4×），
缺乏放大后查看局部、双击、触屏捏合、环绕导航、预加载、幻灯片、计数、旋转等专业看图器常见交互。
本 FR 在 FR-102（视频分支已内嵌播放器直接播放）之上，**只增强图片分支的查看体验**，
不动视频分支、不动后端、不引新依赖。属 P9 前端体验增强。

## 2. 需求（要什么）

范围内（仅图片分支）：
- **缩放后拖拽平移**：放大（zoom>1）后可鼠标拖拽查看图片别处，`transform: translate` 实现，带边界约束回弹。
- **双击放大/复位**：双击在 1×↔2× 间切换。
- **移动端捏合缩放**：触摸双指捏合缩放、单指平移（原生 touch 事件）。
- **上下一项环绕**：`←/→` 与上一项/下一项按钮到头时循环（首↔尾），不再端点禁用。
- **相邻预加载**：预取前后各 1 张原图，切换不闪白。
- **幻灯片**：自动轮播开关（默认 3 秒间隔），播放时自动切下一张。
- **位置计数**：标题区显示「当前 / 总数」（如 3 / 60）。
- **旋转**：左/右旋转 90° 按钮，CSS `rotate` 实现。
- **键盘补全**：`+/-` 缩放、`F` 全屏、`Space` 下一张、`R` 右旋（在既有 `←/→/Esc` 上补）。

不做（范围外）：
- 不动 FR-102 视频内嵌播放器分支。
- 不动后端、不新增接口、不引新依赖。
- 不做 FR-106 的工具栏重做 / EXIF 图标化 / 站内地图，不做 FR-107 统一查看器框架。

## 3. 设计（怎么做）

全部集中在 `frontend/src/components/MediaDetailPanel.tsx` 图片分支：
- 新增状态：`pan {x,y}`、`rotation`（0/90/180/270）、`slideshow`（开关）；既有 `zoom` 复用。
- 图片 `transform` 合成：`translate(pan) scale(zoom) rotate(rotation)`。
- 平移：鼠标 `mousedown/move/up` + 触摸单指拖；捏合：双指 `touchmove` 算距离比缩放。
- 边界约束：按缩放后溢出量夹紧 pan，松手回弹。
- 导航环绕：`goPrev/goNext` 改为对 `files.length` 取模循环。
- 预加载：`useEffect` 监听 idx，`new Image()` 预取相邻 raw。
- 幻灯片：`useEffect` 开关驱动 `setInterval` 自动 `goNext`。
- 换项 / 重开复位 `zoom/pan/rotation`。
- 复用 FR-92 token、FR-93 品牌紫（按钮 `variant`/色随主题）。

无新 ADR。
