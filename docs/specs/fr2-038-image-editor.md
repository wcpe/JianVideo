# 功能规格：图片高级编辑器

> 状态：候选发布@v0.25.0-rc.1　·　关联 PRD：FR2-038　·　阶段：P4 `0.25.x`　·　前置：FR2-037 任务队列

## 1. 背景与目标

P4 提供系统内图片调色覆盖层：曝光/对比/色温等**不改原文件**；导出新文件走任务队列；可重置回原图预览。

## 2. 范围

### 2.1 范围内

- 编辑器 UI：预览 + 参数滑杆（曝光、对比度、饱和度、色温；首期固定集合）。
- 覆盖层状态存会话/可选本地草稿，默认不写库、不写原文件。
- 导出：选择格式（jpeg/png/webp），入队 `image.export` 任务，产物进可重建导出目录，可下载。
- 重置：一键恢复参数默认值与预览。

### 2.2 范围外

- 图层、画笔、裁剪透视等专业修图。
- 写回覆盖原文件（若未来需要，走 FR2-033 高危路径）。
- 批量调色（可后续挂 FR2-053）。

## 3. 设计

- 前端：独立路由或详情内抽屉；预览用 Canvas/CSS filter 近似；导出参数 JSON 提交 API。
- 后端：`POST /api/library/media/:id/image-export` → `tasks.Enqueue(type=image.export)`；worker 用已有 ImageMagick/工具链生成新文件。
- 产物：`exports/{space}/{media_id}/{task_id}.*`，登记任务 result；清理走可重建缓存策略。
- 幂等键：`space+media+params_hash+format`。

## 5. 验收标准

- 调整参数实时预览，不修改原文件字节。
- 导出产生任务且完成后可下载；原文件 hash/size 不变。
- 重置后预览回到原图观感。
- 失败任务可查询错误摘要，不留下半写原文件。

## 6. 风险

- 浏览器预览与导出结果色差：文档标明预览近似、导出以服务端为准。
