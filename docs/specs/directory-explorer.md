# 功能规格：目录资源管理器视图

> 状态：开发中　·　关联 PRD：FR-33　·　依赖：FR-34（详情面板）

## 1. 背景与目标

当前目录浏览（`DirectoryBrowser`）只有单列卡片、单击即开、无排序/多选，不像资源管理器。本功能（P3）增强为类资源管理器：多种展示方式、排序切换、单选/Shift 多选，并接入 FR-34 详情面板。

## 2. 需求（要什么）

- 范围内：
  - 展示方式切换：列表（详情行：缩略图 + 名称 + 大小 + 类型 + 分辨率）/ 大图标 / 中图标 / 小图标（图标网格，缩略图尺寸与每行列数随档位变化）。
  - 排序切换：名称 / 大小 / 类型(扩展名) / 修改时间（升序）；目录恒排在文件前、目录按名称排序。
  - 选择：单击文件单选（替换）、`Shift`+单击区间选、`Ctrl/Cmd`+单击切换；选中高亮。目录单击进入（不参与选择）。
  - 打开：**双击**文件打开 FR-34 详情面板（定位到该文件在当前文件列表的下标），取代原单击打开。
  - 目录页接入 `MediaDetailPanel`（FR-34），替换 `ImagePreviewModal`。
- 不做（范围外）：
  - 批量操作（删除/移动等）：仅做选择与高亮，不加批处理动作（YAGNI，未要求）。
  - 拖拽框选、列排序表头点击排序（用下拉切换即可）。
  - 目录浏览的窗口虚拟化：为支持多展示档位与选择，目录视图改用常规网格/列表（单目录条目有界）；时间轴的大列表仍保留虚拟化。

## 3. 设计（怎么做）

- `DirectoryBrowser` 增 props：`displayMode`（list/large/medium/small）、`sort`（name/size/type/time）、`onOpenFile`（双击触发）。
  - 文件按 sort 排序（纯函数 `sortFiles`），目录按名称排序、恒在前。
  - 列表档：详情行布局；图标档：`SimpleGrid` 列数与缩略图尺寸按档位。
  - 选择：内部 `selectedIds: Set<number>` + `anchorIndex`；click/shift/ctrl 语义如上；选中卡片描边高亮。
- `BrowsePage` 增工具栏：展示方式 `SegmentedControl` + 排序 `NativeSelect`（状态在页持有）；改用 `MediaDetailPanel`，双击文件按其在当前 `files` 的下标打开。
- `ImagePreviewModal` 若全仓库无引用则删除（连带其测试），其下载等能力已被 `MediaDetailPanel`/FR-42 覆盖。

## 4. 验收标准

- 切换展示方式：列表显示详情行、图标档显示对应密度网格。
- 切换排序：文件按名称/大小/类型/时间重排，目录恒在前。
- 单击单选、`Shift` 区间选、`Ctrl` 切换，选中高亮；双击打开详情面板。
- 前端 `npm run build`、`npm run test`（含 DirectoryBrowser 展示/排序/选择测试）全绿。

## 5. 风险 / 待定

- 去虚拟化：单目录条目通常有界，常规渲染可接受；若未来出现超大目录再评估按行虚拟化。
