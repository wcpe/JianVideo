# 功能规格：浏览页信息架构 A（FR-100）

> 状态：开发中　·　关联 PRD：FR-100　·　分支：feature/fr-100-page-ia-a

## 1. 背景与目标

第九期界面信息架构打磨，针对三个浏览/管理页的信息组织做体验改进（扩 FR-14 时间轴 / FR-40 相册 / FR-64 后缀列管）：

- 时间轴页筛选控件多（搜索/收藏/标签/类型/大小/日期/缩放）平铺偏挤，缺乏分组；左侧日期轴视觉弱。
- 相册卡只有图标占位、无封面，难一眼辨识；网格固定列数空间利用一般。
- 存储库管理页每库 33 个后缀徽标平铺成「徽标墙」，是信息噪声、淹没「添加」入口。

属第九期（界面设计系统与播放/图片体验），复用 FR-92 token、FR-93 品牌紫、FR-99 媒体卡组件，纯前端、不动后端、无新依赖、无新 ADR。

## 2. 需求（要什么）

- **时间轴筛选分组 + 日期轴视觉**：筛选区控件按「搜索 | 内容筛选 | 视图」分组成带标签的容器，更清晰；左侧日期轴（年/月-日）做更明显的时间锚视觉。
- **相册卡封面 + 自适应网格**：相册卡加封面（有成员用首个成员的缩略图，空相册给占位插画），网格用 `minmax` 自适应铺满。
- **管理页后缀折叠分组**：后缀徽标墙默认折叠（可展开），分内置/自定义两组，突出「添加」入口。
- 范围内：仅重组上述三页的控件排列 / 分组容器 / 视觉，复用现有端点与组件。
- 不做（范围外）：不新增后端封面端点、不改请求参数与受控逻辑、不破坏 FR-99 sticky 批量条、FR-86 移动端筛选抽屉、FR-64 后缀增删与筛选逻辑。

## 3. 设计（怎么做）

- **TimelinePage.tsx**：把 `filtersContent` 的散控件包进三个带 `dimmed` 小标题的分组 `Box`——「内容筛选」（收藏/标签 + 类型/大小/日期）与「视图」（缩放）；搜索本就在 `filtersContent` 之外常驻（FR-35/FR-86），作为「搜索」组保留。仅改 JSX 容器与标题，受控 state、请求参数、桌面 `visibleFrom` / 移动 `Drawer` 承载结构、FR-99 批量条均不动。
- **TimelineView.tsx → DateGroupRow**：增强左侧日期轴的时间锚视觉——加大圆点、用品牌紫填充、主标签（月-日/年）更醒目，竖线沿用。仅改视觉样式，不改 `splitDate` 分段逻辑与网格。
- **AlbumsPage.tsx**：新增内联子组件 `AlbumCover`——空相册（`item_count===0`）直接渲染占位插画（`IconPhotoOff`），非空相册按需经现有 `albumApi.listAlbumItems(album.id)` 取首个成员、用 FR-99 的 `MediaThumbnail` 渲染封面（`objectFit:'cover'`）。相册卡顶部加 `Card.Section` 封面区；列表网格由固定 `cols` 改 `SimpleGrid` 的 `minmax`（`type="container"` 或 `style` minmax）自适应。仅本页改，不动相册 API。
- **LibraryPathManager.tsx**：后缀区由「常显徽标墙」改为默认折叠——以一个可点的「N 个后缀」摘要行（`UnstyledButton` + 展开图标）控制 `Collapse`；展开后按 `is_builtin` 分「内置 / 自定义」两组渲染徽标；筛选档位（全部/视频/图片，FR-64）保留作用于展开内容。「添加自定义后缀」入口移到摘要行附近以突出。各库折叠态独立 state，缺省折叠。

涉及组件：`TimelinePage` / `TimelineView` / `AlbumsPage` / `LibraryPathManager`。无数据模型 / 接口 / 架构决策改动，无新 ADR。
