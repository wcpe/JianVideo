# 功能规格：视频片段粗剪导出

> 状态：候选发布@v0.25.0-rc.3　·　关联 PRD：FR2-039　·　阶段：P4 `0.25.x`　·　前置：FR2-037、player-core、转码工具链

## 1. 背景与目标

用户在播放页或专用粗剪面板选择起止点，导出片段到新文件；走任务队列；**不改原文件**；产物可下载。

## 2. 范围

### 2.1 范围内

- UI：起止点选择（秒/帧近似）、时长预览、导出格式（mp4/mkv 等白名单）。
- API 入队 `video.clip.export`；worker 调用 ffmpeg 按起止裁剪（优先 stream copy，失败再重编码策略可配置但首期固定简单策略）。
- 产物进导出目录；任务 result 含下载路径。

### 2.2 范围外

- 多段时间线、转场、字幕烧录、调色。
- 覆盖原文件。
- 匿名分享触发导出（禁止）。

## 3. 设计

- `POST /api/library/media/:id/clip-export` body：`start_sec`、`end_sec`、`format`。
- 校验：`0 <= start < end <= duration(+epsilon)`；最大时长上限防滥用（可配置，默认 2h）。
- 幂等键含 media、起止、格式。
- 播放页入口与任务中心状态展示。

## 4. 任务拆分

- [x] 规格冻结（本文）。

## 5. 验收标准

- 合法起止导出成功，文件可播放且时长近似 end-start。
- 原文件未变；任务失败不产生损坏原片。
- 非法起止返回 400 中文错误。
- 导出不经匿名分享路径触发。

## 6. 风险

- 非关键点剪切与 codec 限制：首期允许重编码回退并在任务日志标明。
