# ADR-0049：时间轴导航形态重构（移除左轴，右侧统一完整时间轴）

## 状态
已接受

## 背景
当前时间轴为"左侧竖向日期轴 + 右侧标尺预览"形态（FR-B / FR-14，FR-120 升级为苹果风右侧标尺 hover 预览）。左侧竖轴存在缺陷，且与右侧标尺职责重叠，造成导航割裂、体验不连贯。

## 决策
移除左侧竖向日期轴；右侧标尺升级为唯一完整时间轴导航（年 / 月刻度 + hover / 拖动缩略图预览 + 点击跳转），媒体网格占满主区（FR-138）。本决策**取代 FR-120 / AC-24 中"左竖轴 + 右标尺"并存的形态部分**。

## 理由
- 单一时间导航入口，消除左右两套导航的割裂与左轴缺陷。
- 网格占满主区提升信息密度与浏览效率。
- 与主流相册（Apple / Google Photos）右侧时间轴交互一致，降低学习成本。

## 后果
- TimelineView / TimelinePage / TimelineScrubber 需重构（强耦合，串行推进）。
- AC-24（FR-120）相关"左轴"验收项作废，以 FR-138 新验收（AC-42）为准。
- ADR-0017（时间轴前端架构：zustand + axios 分页）仍有效，本 ADR 仅改导航形态、不改数据层。

## 备选方案
- 保留左轴仅修 bug：左右两套导航割裂依旧，不解决根本问题。
- 仅右侧标尺、不做预览增强：达不到"完整时间轴 + 预览"目标。
