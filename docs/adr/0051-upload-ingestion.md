# ADR-0051：Web 上传入库路径与命名规则

## 状态
已接受

## 背景
媒体入库真源为"扫描本地目录"（library_paths + watcher + ScanLibrary，FR-01）。用户需要在 Web 端上传文件入库（FR-149）。当前无任何上传端点 / UI。

## 决策
新增 Web 上传：文件经后端 multipart 接收并**落盘到"上传目标位置"，随后触发增量扫描入库**（保持"磁盘文件为入库真源"不变，上传仅是又一个落盘入口）。目标位置可在设置中配置默认值、并允许上传时临时选择；目录与文件命名规则可配置（"保留原样" / "按规则整齐归档"两档）。仅接受图片 / 视频。

## 理由
- 复用既有"落盘 → 扫描 → 入库"链路，不破坏真源一致性（media_files 仍由扫描填充）。
- 命名规则可配置，兼顾"原样"与"整齐归档"两类用户习惯。
- 落盘目标须为已注册库目录，确保上传内容能被扫描索引。

## 后果
- web → library 新增上传端点（multipart 接收、路径校验、落盘、触发扫描）；settings 增上传相关键（默认位置、命名规则）。
- 须校验目标路径合法性、防止越权写入库外目录、处理重名 / 冲突。
- 删除源文件 / 重复上传由现有扫描与软删 / 去重逻辑处理。

## 备选方案
- 上传直接写 media_files 不落盘：违反"磁盘文件为入库真源"，否决。
- 仅命令行 / 手动放文件：不满足 Web 上传需求。
